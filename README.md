# Coding Shack Portal

A 2-app system for Coding Shack students and admins.

## Apps
- `index.html` = Admin Dashboard. Manage students, settings, announcements, AI Brain
- `student.html` = Student Portal. Login, view grades, announcements, ask AI

## Setup
1. Create Google Sheet with tabs: SETTINGS, STUDENTS, ANNOUNCEMENTS, AI_BRAIN
2. File > Publish to web > CSV for each tab
3. Paste the 4 CSV links in both HTML files
4. Host on GitHub Pages or Netlify

## Data Structure
See Google Sheet tabs for columns.
